# 適性研究 集計 Focus Design（CPL-DEV）

- メインは基本5条件、最多組み合わせの馬体図、上位3組、詳細入口の順。結果カード右上の「この条件で集計」でのみRPCを実行する。選択中の5条件と確定条件を分離し、変更中は旧結果のTOP3・詳細をロックする。
- 要求中は連打を防止し、結果が揃ってから確定条件・n・TOP3・馬体色を一括更新して1位を選ぶ。0件時は旧色と旧TOP3を消して「該当データなし」とする。エラー時は旧確定結果を維持し、古い非同期応答はリクエスト番号で破棄する。
- 初めて集計画面を開いた際、すでに保存済みの基本5条件が揃っていれば一度だけ表示用に読み込む。以降、条件編集だけではRPCを実行しない。未選択・0件では空の大きな馬体カードを表示せず、詳細入口も隠す。
- 詳細を開いた時だけ、クラス・人気で保存済み適性観察を絞る。既存のユーザー別RLSに従い、`races`との内部結合で基本5条件を適用し、500件単位で全件取得して24通りとハリを計算する。メインの結果には詳細条件を適用しない。
- DB、RPC、保存形式、研究入力は変更しない。Ver.55の馬体画像、胸前・トモSVGマスク、6色定義を固定する。正式版への昇格はiPhone実機確認後。
