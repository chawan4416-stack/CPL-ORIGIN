# 適性研究 集計 Focus Design（CPL-DEV）

- メインは基本5条件、最多組み合わせの馬体図、上位3組、詳細入口の順。5条件の変更は確認ボタンなしで既存の適性集計RPCを再実行し、n・TOP3・色を同時更新する。順位選択は表示色だけを切り替え、条件変更時には新しい1位を再選択する。
- 要求中は以前の馬体図と順位を隠し、0件時は「該当データなし」とする。古い非同期応答はリクエスト番号で破棄する。
- 詳細を開いた時だけ、クラス・人気で保存済み適性観察を絞る。既存のユーザー別RLSに従い、`races`との内部結合で基本5条件を適用し、500件単位で全件取得して24通りとハリを計算する。メインの結果には詳細条件を適用しない。
- DB、RPC、保存形式、研究入力は変更しない。Ver.55の馬体画像、胸前・トモSVGマスク、6色定義を固定する。正式版への昇格はiPhone実機確認後。
