# CPL-DEV 状態研究集計 Ver.1.0

- 上部ナビは適性研究・状態研究・記録の3項目。各研究画面の「集計を見る」からその研究の集計へ進む。集計内の切替タブは設けない。基本5条件は既存の検索UIとマスターを共用する。
- 状態集計の主カードには選択条件、n、複勝圏率、1〜3着の各割合、着外率を表示する。イレ込み・発汗のあり／強比較は主カードの下へ置き、詳細はその次に開く。
- `0027_condition_distribution.sql` は新しい読取RPCのみを追加。保存形式、既存集計RPC、入力UIは変更しない。
- 観察IDを単位に、記録された7状態だけを展開する。1件に複数状態があれば各状態へ1件ずつ、同一状態内ではIDを重複計上しない。
- `finished` の公式着順1〜3を複勝圏、4以上を着外とし、その合計だけを率の分母 `n` とする。`dnf` と `scratched` は詳細に件数を残し、分母から除く。同着は同じ公式着順の複数観察として数える。
- 詳細のクラスと人気は共通5条件とは別にRPCで絞る。人気指定時は人気NULLの取消が対象外になる。
- RPCは `security invoker`、認証ユーザーのみ実行可能。レース作成者条件と既存の両テーブルRLSでユーザーを分離する。
- 0件から割合を出さず、着順分布は保存された着順だけを表示する。
- DEV実機確認後に正式昇格を判断する。正式ブランチと正式DBには今回の変更を適用しない。
